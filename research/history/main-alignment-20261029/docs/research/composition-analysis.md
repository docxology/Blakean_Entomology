# Composition analysis contracts

This layer adds a private query-channel policy over
`blake.methods.composition`. The public API owns all composition, concentration,
rational-mass thresholds and group-omission mathematics. Existing SDK methods own
NFKC category matching, literal word envelopes, token denominators and exact whole
text deduplication. The private adapter selects the unchanged registry's seven
name-family groups and twelve explicit singular literal pairs at 8, 32 and 64
words, plus separate whole-unit scope.

All 102 categories and 376 forms remain in the registry. The selected name channel
contains 82 categories. Name families retain derivatives, overlaps and ambiguous
senses. Copies and recorded work IDs are not independent works or organisms.
Zero-mass groups have undefined composition, remain in the complete matrix and
are excluded from the equal-composition mean. The old eleven decisions remain
bound to their original run; no text/image reading credits are created here.

## Explicit portable inputs

Run from the private project root, using an already provisioned environment.
Set the variables to the intended input files; no epoch or machine path is inferred.

```sh
uv run --no-sync python -m blakean_entomology.cli composition-audit \
  --atlas "$ATLAS" --atlas-sha256 "$ATLAS_SHA256" \
  --sensitivity "$SENSITIVITY" --bundle "$BUNDLE" --pin "$PIN" \
  --vocabulary "$VOCABULARY" --proximity "$PROXIMITY" \
  --output analysis_output/composition-expansion-01
```

`tools/audit_composition.py` exposes the same arguments. Ordinary application
imports do not import Matplotlib. Root chooses a **fresh** epoch after installing
a new Git-pinned SDK; an occupied output, including an incomplete epoch, refuses.

The generator verifies the trusted atlas hash, corpus identities, canonical
registry digest, exact runtime profiles, sensitivity and proximity bindings, and
all actual portable source bytes. It recomputes the complete atlas, primary
sensitivity and historical literal experiment using the current imported SDK.
The atlas comparison excludes only its explicitly named producer and historical
review fields; all numbers, profiles and denominators must remain identical.
Historical producer fields are retained separately beside current producer fields.
No old receipt is rewritten or rebaselined.

The run records imported package locations and a namespaced hash closure containing
all actual method, text-search and application Python modules plus the SDK entry
modules. Installed distribution metadata, including `direct_url.json`, is recorded
separately: it does not identify code shadowed by `PYTHONPATH`. Qualification with
worktree source imports is explicitly a source candidate, not installed-Git proof.

Regular input bytes, portable bundle validity and actual producer bytes are checked
before and after computation and immediately around publication. Manuscript text
and image reading metadata are outside this analytical producer contract and may
advance in their separately owned epochs.

## Products and figures

Nine text-free exports comprise the composition receipt, category and omission
tables, full name/work matrix, source-channel and category-channel tables, literal
relationship receipt, and pair and pair/work tables. `run.json` is the completion
marker and is published last. SDK regular-file readers, directory guards, exclusive
reservation, checksum verification and complete-byte publishers own storage.
Failed partial directories remain available for inspection.

```sh
uv run --no-sync python tools/build_composition_figures.py \
  --packet analysis_output/composition-expansion-01 \
  --run-sha256 "$RUN_SHA256" \
  --output analysis_output/composition-figures-expansion-01
```

The plotter checks all nine artifact hashes, typed tables, complete category/group
and pair/window membership, denominators and cross-table totals before reserving
output. Four PNG/SVG/PDF figures receive SDK file receipts and sidecars binding
analytical data, actual plotting/application sources, profiles, denominators and
interpretation limits. `figures.json` is published last after rechecking data and
producer bytes. Matrix shade uses log candidate token rates; pair/work shade uses
within-group matched fractions; source-channel shade uses within-cohort candidate
shares. Printed counts and unit/token denominators remain explicit.

The Matplotlib adapter declares a narrow structural Protocol for every operation
and argument used. Its assignments are checked against the real library types;
real figure subprocess tests execute all methods and formats. There are no casts,
new `Any` annotations or disabled diagnostics. Producer rendering is separate from
root's native manuscript sizing, rendering and independent visual acceptance.

## Qualification boundaries

The focused generic tests must run in the existing external Python 3.9 and 3.11
environments. Use `--noconftest` and a focused pytest configuration: the public
repository's unrelated conftest imports a legacy runtime PEP 604 annotation that
fails on Python 3.9. Retain that failure receipt. New-module coverage is scoped to
the generic and private adapter modules separately and does not certify repository
coverage. The existing public typing holds and full public regression remain
root-owned. Full current private tests, Ruff format/lint and strict `src` checking
must remain clean. Real malformed, mismatched, occupied, linked and out-of-root
inputs must fail before completion publication while preserving existing bytes.
