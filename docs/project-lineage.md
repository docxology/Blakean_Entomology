# Corpus, methods and application lineage

This project adapts the research architecture of
[Blakean Federalism](https://github.com/docxology/Blakean_Federalism): a private
application, an explicit corpus pin, independent ignored local data, source and
reading ledgers, falsifiable software checks, and an argument distinct from its
retrieval counts. It starts a new research question and evidence history.

Federalism's frozen corpus, institutional model, political claims, quotation
ledger, rendered releases and historical acceptance records are not copied into
this project. Its active paper and earlier pin remain intact. No review credit
or release verdict transfers between projects.

| Owner | Responsibility |
|---|---|
| Public `blake` | Source acquisition/custody, recovery verification, passage model, normalization, portable corpus snapshots, generic lexical study engine. |
| Private `Blakean_Federalism` | Political query registry, institutional experiments, interpretation, paper and its own fixed evidence epochs. |
| Private `Blakean_Entomology` | Invertebrate vocabulary, ambiguity coding, contextual research, review decisions, article and application-specific summaries. |

Entomology imports `blake.applications` and `blake.studies`. It does not query an
undocumented SQLite schema or import Federalism's code. Import receipts bind
captured source, projection and index hashes; a Git commit name and the Blake
software version are separate identities. Paper revisions never silently rebase
the corpus or promote retrieval leads into verified animal references.

The initial [parity receipt](../research/federalism-parity.json) verifies exact
equality of all 2,067 portable passage payloads against Federalism's qualified
historical SQLite import, with the original index hash unchanged. This verifies
the shared input seam; it does not rerun Federalism's analyses, repin its paper,
or transfer its acceptance to Entomology. The two methods use independently
specified tokenization and query registries, so matching input bytes do not
promise identical analytical outputs.
